# pair-wise-yf-58 功能开关和灰度发布控制台

## 源提示词摘要
产品负责人配置目标用户、地区、应用版本和依赖条件，研发负责人审批发布计划，值班人员观察过程并随时关闭开关。系统支持规则组合、流量逐步增加、定时生效、紧急停止、回滚，并能在保存前模拟不同用户的命中版本。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 功能开关、发布计划、审计记录、依赖关系、重算任务五类业务对象。
- 规则组合、模拟用户命中、逐步调整流量和定时生效。
- 产品/研发双审批、开始灰度、紧急停止、回滚和恢复草稿。
- 离线提示、VeeValidate + Zod 精确校验和 localStorage 持久化（schema v2）。

## 依赖与并发控制
- **多前置依赖**：每个开关可挂多个前置开关；命中模拟按 DFS 后序展开最终依赖链（前置在前、目标在末）。
- **环路拦截**：保存依赖时做图环路检测，阻止自依赖/成环，并列出环路上涉及的开关名称与 key。
- **级联失效**：父开关停用/改依赖/改放量/急停/回滚时，全部子孙开关已生效的计划立即置为「已失效」、立即停止命中并清空审批，需重新双审批；改动开关自身只回到草稿，不强制停用。
- **断点续算**：级联改动创建命中范围重算任务，按批次推进并落检查点；刷新会标记中断并在启动时自动从断点续跑；写入失败停在断点，可手动「从断点继续重试」（界面提供故障演练按钮）。
- **结果分区**：评估结果以「已生效（绿）/已失效（红）」标签和结果表区分，附最终依赖链与拒绝/失效原因。
- **乐观锁**：依赖与放量提交携带读取时的 `rev`；两人并发时后提交者收到冲突提示（双方版本号与服务端现值），先前结果和本地待提交修改都保留，可选择拉取最新。
- **命中模拟**：逐节点展示依赖链通过/拒绝，给出首个拒绝节点原因（如「被前置开关 X 拒绝：已停用/地区/版本/灰度桶」）。
